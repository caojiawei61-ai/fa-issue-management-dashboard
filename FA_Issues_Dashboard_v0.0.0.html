Version history

Key changes are tracked here so reviewers know what changed before the file is uploaded to GitHub.

Owner / PM · Amber Cao

  • Created and maintained by Amber Cao.
  • release or optimize by Amber Cao

v1.6 · PPT export optimization

  • Optimized PPT export to prevent PIC images from overlapping the title/header area.
  • Reworked Format-2 PPT layout so the exported one-pager follows the web view proportions more closely.
  • Adjusted PPT text auto-fit: keep web-like font size first, then shrink only when content exceeds the 16:9 slide frame.
  • Preserved image aspect ratio more safely in exported slides.
  • release or optimize by Amber Cao

v1.5 · Multi-format one-pager templates

  • Added Format-2 based on uploaded PPT reference while keeping 16:9 canvas.
  • New FA record starts with a format chooser containing editable format names and visual previews.
  • Existing FA records can switch format without changing Tracker or source data.

v1.4 · Category filtering and tracker category column

  • Added Category field with Material, Man handling, Equipment, Method, and TBD options.
  • Added Tracker Category column after PIC and a category filter next to All status.
  • Existing records without Category remain compatible and display as TBD.

v1.3 · Tracker manual edit and smart import

  • Double-click Tracker cells to edit the selected cell and save back to the linked One-pager.
  • Double-click still supports full FA Edit mode and protected Delete mode.
  • Added smart import for PPTX, Keynote package, and Excel files to prefill FA fields; unrecognized fields are highlighted in red for manual completion.

v1.1 · Tracker summary refinement

  • Removed Repeat rate, Open aging, and DRI overdue columns from Tracker.
  • Tracker Issue, FA Findings, and Next steps / Corrective Actions now auto-summarize from the linked one-pager.
  • Tracker auto-generated summary text uses blueberry color.
  • PIC thumbnail fills the cell as much as possible without stretching or distortion.
  • FR and Impact / Risk are separated by one blank line in the Tracker Issue cell.

v1.0 · Initial editable FA dashboard

  • Created Z01 FA Tracker and linked one-pager workflow.
  • Added editable FA record form, risk maturity colors, issue trend arrows, PIC upload, local save, edit, delete, and PPTX export.
  • Established 16:9 one-pager layout based on FA one-pager reference format.
